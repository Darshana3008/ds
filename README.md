## 🎯 About the Project
Balancing rigorous academic coursework with personal well-being is one of the most vital life skills a university student can develop. This project bridges simple Python programming logic with daily habit tracking, helping users monitor hydration, focused study intervals, and mental mindfulness. Designed with simplicity in mind, it provides immediate feedback and records progress persistently to encourage long-term behavioral consistency.

---

## ✨ Key Features
* **Daily Metric Logging:** Easily log daily water intake (liters), focused study blocks (hours), and mindfulness/meditation practice (minutes).
* **Instant Evaluation & Feedback:** Receive automated, encouraging assessments of your daily habits against baseline wellness goals.
* **Persistent Storage:** Automatically writes and appends daily logs to a local `habit_log.txt` file so you can review your history over time.
* **Built-in Wellness Tips:** Quick access to practical tips on cognitive focus, time management techniques (like the Pomodoro method), and stress reduction.
* **Zero External Dependencies:** Built entirely using Python's standard library (`datetime`), making it fast, lightweight, and instantly runnable anywhere.
